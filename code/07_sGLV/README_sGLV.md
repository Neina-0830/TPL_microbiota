# sGLV calibration and process-intensity workflow

This directory contains the cleaned stochastic generalized Lotka–Volterra (sGLV) workflow used to calibrate the model and evaluate how temporal Taylor's power-law scaling responds to modeled immigration, species-specific growth, interspecific interactions and multiplicative stochastic noise.

The cleaned workflow separates **external inputs** from **generated outputs**:

- external files are read only from `./data/` (sGLV-specific parameter files are under `./data/sGLV/`);
- generated simulations and calibration products are written to `./results/17_sGLV/`;
- phylogenetic-distance objects used for pTTPL are generated by the empirical pTTPL workflow under `./results/pairwise_distance/`.

Historical filenames retain the prefix `SLM` for compatibility with the supplied analysis files, but the model is referred to as **sGLV** in the manuscript.

## Workflow

| Step | Script | Purpose |

| C17 | `16_check_sGLV_inputs.py` | Preflight check for condition-specific model-derived inputs in `./data/sGLV/` |
| C18 | `sGLV_core.py` | Shared simulation engine, group grids and process-intensity parameterization |
| C19 | `17_sGLV_calibration_simulate.py` | Generate warmed and unwarmed calibration-grid simulations |
| C20 | `18_sGLV_resample.R` | Resample simulations to the group-specific sequencing depth |
| C21 | `19_sGLV_calibration_TPL.R` | Recalculate tTTPL and pTTPL for calibration-grid simulations |
| C22 | `20_sGLV_calibration_community_metrics.R` | Reconstruct empirical Bray/richness targets from `./data/` and calculate calibration discrepancies |
| C23 | `21_sGLV_select_top10.R` | Combine calibration components and retain the ten lowest-loss parameter sets |
| C24 | `22_sGLV_process_intensity_simulate.py` | Generate continuous process-intensity simulations for the retained ensembles |
| C25 | `23_sGLV_tTTPL_process_intensity.R` | Recalculate tTTPL along the process-intensity gradient |
| C26 | `24_sGLV_pTTPL_process_intensity.R` | Recalculate pTTPL along the process-intensity gradient |
| C27 | `25_sGLV_process_intensity_importance.R` | Calculate AUC-based relative sensitivity, signed/endpoint diagnostics and warming-contrast sensitivity |

Supporting files are `sGLV_group_config.csv`, `sGLV_calibration_weights.csv` and `requirements_sGLV.txt`.

## Inputs

The observed community tables used to reconstruct empirical Bray–Curtis and richness calibration targets are the same five taxon tables stored at the top level of `./data/`. No separate precomputed diversity-target directory is required.

The dynamic simulations additionally require the original model-derived parameter inputs under `./data/sGLV/`. These include condition-specific initial abundance, relative immigration, relative growth and interaction-matrix files. Their exact layout is documented in [`../../data/sGLV/README.md`](../../data/sGLV/README.md).

These parameter files are not inferred automatically from the uploaded community tables because doing so would change the original sGLV parameterization. Before running the calibration grid, check them with:

```bash
python code/07_sGLV/16_check_sGLV_inputs.py
```

## Calibration

For each soil-biotic group and warming condition, the calibration grid varies immigration, interaction strength, growth scaling and stochastic-noise amplitude. Group-specific grids and the warmed/unwarmed drift scaling used for the noise component are recorded explicitly in `sGLV_group_config.csv`.

After simulation and fixed-depth resampling, `19_sGLV_calibration_TPL.R` calculates simulated βt and βp. `20_sGLV_calibration_community_metrics.R` reconstructs the empirical temporal Bray–Curtis, warming-versus-unwarming Bray–Curtis and richness-ratio targets directly from the raw community tables and sample metadata in `./data/`, following the structure of the supplied legacy calibration code.

For each group and TPL formulation, the calibration loss is:

```text
Loss =
    Beta_difference
  + Delta_beta_difference
  + (TemporalBrayDifference + SpatialBrayDifference) / BrayDivisor
  + RichnessRatioDifference / RichnessDivisor
```

The group- and TPL-specific scaling divisors recovered from the supplied calibration scripts are stored in `sGLV_calibration_weights.csv`. The ten parameter sets with the smallest total loss are retained as an ensemble of near-optimal parameterizations. The tTTPL and pTTPL ensembles are selected separately.

## Process-intensity analysis

Each retained parameter set is perturbed along

```text
z = 0, 0.25, 0.50, 0.75, 1
```

with `z = 1` representing the calibrated model. Only one process is varied at a time while the other components remain at their calibrated values:

```text
immigration(z) = z × immigration_calibrated
noise(z)       = z × noise_calibrated
interaction_offdiag(z) = z × interaction_offdiag_calibrated
interaction_diag(z)    = -1

growth(z) =
    (1 - z) × homogeneous_growth
  + z × species_specific_growth_calibrated
```

Each rank × process × condition × intensity combination is repeated using three stochastic seeds (`0`, `1`, `2`).

The primary sensitivity measure is the integrated absolute deviation of β from its calibrated value across the full intensity gradient. Sensitivities are first summarized across stochastic seeds within each retained parameter set and then normalized across the four processes. The ten retained parameter sets are treated as alternative calibrated solutions, not as independent biological replicates.

## Run order

Run from the repository root.

```bash
# 1. Check model-derived inputs
python code/07_sGLV/16_check_sGLV_inputs.py

# 2. Calibration simulations (example; use HPC chunking as needed)
python code/07_sGLV/17_sGLV_calibration_simulate.py \
  --group Archaea --condition warming

# 3. Fixed-depth resampling
TPL_SGLV_RESAMPLE_MODE=calibration \
Rscript code/07_sGLV/18_sGLV_resample.R

# 4. Calibration statistics
TPL_SGLV_CALIBRATION_TPL=both \
Rscript code/07_sGLV/19_sGLV_calibration_TPL.R
Rscript code/07_sGLV/20_sGLV_calibration_community_metrics.R
Rscript code/07_sGLV/21_sGLV_select_top10.R

# 5. Process-intensity simulations for the separately calibrated ensembles
python code/07_sGLV/22_sGLV_process_intensity_simulate.py \
  --tpl tTTPL --group all --condition both
python code/07_sGLV/22_sGLV_process_intensity_simulate.py \
  --tpl pTTPL --group all --condition both

# 6. Resample and refit TPL
TPL_SGLV_RESAMPLE_MODE=process_intensity TPL_SGLV_TPL=both \
Rscript code/07_sGLV/18_sGLV_resample.R
Rscript code/07_sGLV/23_sGLV_tTTPL_process_intensity.R
Rscript code/07_sGLV/24_sGLV_pTTPL_process_intensity.R

# 7. Process-sensitivity summaries
Rscript code/07_sGLV/25_sGLV_process_intensity_importance.R
```

For a large calibration grid, `17_sGLV_calibration_simulate.py` supports `--start-index` and `--stop-index` so jobs can be distributed across an HPC system.

## Interpretation

The sGLV analysis is used as an empirically informed **process-sensitivity framework**, not as a unique reconstruction of the field mechanism. In particular, the condition-specific noise parameterization is informed in part by iCAMP-derived drift, so the sGLV and iCAMP analyses should not be interpreted as fully independent mechanistic tests. The process-intensity analysis also does not diagnose transitions among stable, oscillatory or chaotic dynamical regimes.
