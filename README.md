# Temporal variance scaling across diverse soil microbiota

Reproducible analysis code for the manuscript **“Experimental Warming Amplifies Temporal Variance Scaling Across Diverse Soil Biota.”**

This repository contains the canonical workflow used to quantify temporal Taylor’s power-law (TPL) scaling across five soil-biotic groups, test long-term global-change effects under the blocked split-plot experiment, evaluate phylogenetic and subgroup robustness, resolve environmental pathways, and examine process sensitivity with iCAMP and stochastic generalized Lotka–Volterra (sGLV) models.

The repository has been organized so that **all external input files are read from `./data/`** and all generated analysis products are written to `./results/`. Machine-specific absolute paths are not required.

> **Reproducibility principle.** `CODE_LIST_GITHUB.csv` is the authoritative one-to-one index between analysis IDs used below and the scripts in `code/`. Legacy and superseded development scripts are intentionally excluded from the canonical workflow.

---

## Study design

The experiment is a long-term multifactor grassland manipulation with warming, altered precipitation and annual clipping. The analysis uses:

- **4 blocks × 6 whole plots = 24 whole plots**;
- each whole plot split into clipped and unclipped subplots, giving **48 subplot trajectories**;
- annual samples from **2010–2020 (11 years)**, giving **528 samples per soil-biotic group**;
- five groups: **Bacteria, Archaea, Fungi, Protists and Nematoda**.

Two temporal TPL formulations are analyzed:

- **tTTPL (`βt`)** — the cross-taxon slope of log temporal variance versus log temporal mean relative abundance within each 11-year subplot trajectory;
- **pTTPL (`βp`)** — the corresponding temporal scaling relationship for each taxon’s normalized contribution (`MPD_i,k`) to abundance-weighted community phylogenetic structure.

The primary treatment model for both formulations preserves the experimental hierarchy:

```r
beta ~ WarmF * PrecipF * ClipF + (1 | Block/WholePlotID)
```

Precipitation is treated as a categorical three-level factor. Overall factor effects and treatment-specific contrasts are therefore distinct estimands: Fig. 2a uses marginal factor-level effects, whereas treatment-specific analyses compare the 11 treatment combinations with the control.

## Analysis workflow

### 1. Whole-community temporal TPL

| ID | Script | Main role |
|---|---|---|
| C01 | `code/01_empirical_TPL/01_tTTPL_fit_and_robustness.R` | Fit subplot-level `βt`; detrending, reference-variance, compositionality and whole-community temporal-variability robustness analyses |
| C02 | `code/01_empirical_TPL/02_tTTPL_factorial_statistics.R` | Hierarchical factorial inference, marginal factor effects and 11 treatment-versus-control contrasts for tTTPL |
| C03 | `code/01_empirical_TPL/03_pTTPL_prepare_MPDik_by_plot.R` | Calculate abundance-weighted MPD, `MPD_i,k`, and portable pairwise phylogenetic-distance objects |
| C04 | `code/01_empirical_TPL/04_pTTPL_fit_full_precision.R` | Fit full-precision subplot-level `βp` |
| C05 | `code/01_empirical_TPL/05_pTTPL_factorial_statistics.R` | Hierarchical factorial inference for pTTPL |

The revised slope-fitting scripts retain full numerical precision in downstream analyses. Slope-estimation uncertainty is additionally evaluated in sensitivity analyses rather than replacing the primary split-plot model.

### 2. Tip-shuffle phylogenetic null model

`C06` (`code/02_tipshuffle_null/06_pTTPL_tipshuffle_null_analysis.R`) randomizes taxon labels among phylogenetic tips while retaining empirical abundance/occurrence trajectories, tree topology and branch lengths. For each subplot, the mean of 100 null `βp` estimates is compared with the matched observed `βp` using a two-sided paired Wilcoxon signed-rank test; the five group-level P values are Holm-adjusted.

The null analysis tests whether the empirical correspondence between taxon identity and phylogenetic position contributes to pTTPL scaling. The 100 randomizations are Monte Carlo null realizations, not biological replicates.

### 3. Phylum and trophic-group analyses

| ID | Script | Main role |
|---|---|---|
| C07 | `code/03_subgroup_TPL/07_tTTPL_subgroup_fit.R` | Full-precision subgroup tTTPL fitting |
| C08 | `code/03_subgroup_TPL/08_pTTPL_subgroup_fit.R` | Full-precision subgroup pTTPL fitting |
| C09 | `code/03_subgroup_TPL/09_subgroup_factorial_statistics.R` | Coverage filtering, effect sizes and hierarchical treatment contrasts |

Microbial subgroup analyses use phylum membership; Nematoda subgroup analyses use the trophic annotations included in the uploaded Nematoda taxonomy file. Reliability criteria for fitting a subplot slope are kept separate from the coverage criteria used for treatment inference and visualization.

### 4. Environmental associations and mixed-effects piecewise SEM

`C10` (`09_prepare_environment_SEM_inputs.R`) aggregates the sample-level environmental table to the subplot scale. Eleven-year means and temporal coefficients of variation are calculated for the environmental and ecosystem-function variables and merged with `βt`, `βp` and treatment metadata.

The primary environmental pathway workflow is:

```text
C10 -> C11 (model specification)
    -> C12 (shared split-plot SEM engine)
    -> C13 (tTTPL piecewise SEM)
    -> C14 (pTTPL piecewise SEM)
```

The SEMs use a prespecified environmental backbone and group-specific paths to the TPL endpoint. Each component model retains the blocked split-plot random structure. No automated forward, backward or stepwise path selection is used. Path and total-effect uncertainty is evaluated with whole-plot cluster bootstrap, together with leave-one-block-out robustness analysis.

### 5. Ecosystem-function associations

`C15` (`code/05_ecosystem_function/14_ecosystem_function_incremental.R`) evaluates whether TPL β provides explanatory information for ecosystem-function variation beyond mean soil temperature.

For each ecosystem-function property, nested split-plot mixed models compare a temperature-only/treatment model with the corresponding model additionally containing standardized β. Reported quantities include the conditional β coefficient, marginal R², Δ marginal R², likelihood-ratio comparison, ΔAIC and whole-plot bootstrap intervals.

These analyses are interpreted as **conditional associations and incremental explanatory power**, not causal variance partitioning.

### 6. iCAMP community-assembly analysis

`C16` (`code/06_iCAMP/15_iCAMP_process_summary.R`) provides the cleaned raw-data-to-summary iCAMP workflow. Community, phylogeny and taxonomy inputs are read from `./data/` / `./data/prepared/`; generated iCAMP objects and process summaries are written under `./results/14_iCAMP/`.

The script preserves the supplied Confidence-based iCAMP settings, including `ds = 0.2`, `bin.size.limit = 24`, `phylo.metric = "bMPD"`, and 200 randomizations. Because the supplied source established these settings for the Bacteria analysis, application to another group should use the group-specific settings from the corresponding validated original analysis rather than assuming that the Bacteria binning choice is universal.

### 7. sGLV calibration and process-intensity sensitivity

The full sGLV workflow is documented separately in `code/07_sGLV/README_sGLV.md`.

The canonical stages are:

```text
C17  check model-derived inputs in ./data/sGLV
C18  shared sGLV engine
C19  calibration-grid simulation
C20  fixed-depth resampling
C21  calibration tTTPL / pTTPL
C22  empirical-versus-simulated Bray/richness calibration metrics
C23  retain the ten lowest-loss parameter sets
C24  continuous process-intensity simulations
C25  tTTPL over the process-intensity gradient
C26  pTTPL over the process-intensity gradient
C27  AUC-based process-sensitivity summaries
```

The revised process-intensity analysis varies immigration, species-specific growth, interspecific interactions and stochastic noise separately over

```text
z = 0, 0.25, 0.50, 0.75, 1
```

with `z = 1` corresponding to the calibrated model. Three stochastic realizations are used for each retained parameter set, condition and intensity. Sensitivity is summarized first within each of the ten retained parameter sets and then across that ensemble; parameter sets and stochastic seeds are not treated as independent biological replicates.

#### Additional sGLV inputs

The five primary community tables are sufficient for the empirical TPL analyses and are also used by C22 to reconstruct the observed Bray–Curtis and richness calibration targets. The simulations themselves additionally require the **original model-derived immigration, growth and interaction structures** under `./data/sGLV/`.

Those model-derived files are not reconstructed automatically from the uploaded taxon tables because doing so would change the original parameterization. Their expected layout is documented in `data/sGLV/README.md`; run:

```bash
python code/07_sGLV/16_check_sGLV_inputs.py
```

before starting the calibration grid.

The sGLV analysis is interpreted as an empirically informed process-sensitivity analysis. It is not treated as an independent mechanistic validation of iCAMP, because the condition-specific stochastic-noise parameterization is informed in part by iCAMP-derived drift.

## Statistical conventions

### Experimental hierarchy

All primary treatment inference preserves the 48 subplot trajectories nested within 24 whole plots and four blocks. Cohen’s d / Hedges’ g values are descriptive standardized effect sizes; formal inference comes from the hierarchical models.

### Multiplicity

- overall factor effects: Holm adjustment across the four prespecified factor-level contrasts within each group × TPL formulation;
- treatment-specific analyses: Holm adjustment across the 11 treatment-versus-control contrasts within each group × TPL formulation;
- subgroup analyses: Holm adjustment across the 11 treatment-versus-control contrasts within each eligible subgroup;
- tip-shuffle comparison: Holm adjustment across the five group-level paired tests.

### Whole-community temporal variability

The primary community-level metric is the root-mean-square Hellinger distance of the 11 annual community profiles from their temporal centroid. It measures temporal compositional displacement and is not interpreted as an estimate of aggregate abundance stability or taxon synchrony.
